# Student Management System
A Python-based Student Management System developed using Object-Oriented Programming (OOP).
## Features
- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Exit the application

## Technologies Used

- Python
- Object-Oriented Programming (OOP)

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run the following command:

```bash
python student.py
